# Jogos — Memória & Neon Racer

Este repositório contém dois jogos feitos com HTML, CSS e JavaScript puro. Não precisa instalar dependências.

## Jogo da memória

Abra `index.html` no navegador. Tem três dificuldades, cronômetro, movimentos e progresso.

## Corrida arcade 6-bit

Abra `corrida.html` no navegador para jogar **NEON RACER**.

- Setas esquerda/direita ou teclas A/D para mudar de faixa.
- Espaço para pausar.
- No celular, use os botões na tela.
- Desvie dos carros, acumule pontos e bata seu recorde.
- O recorde fica salvo no navegador.

## Rodar com servidor local

Na pasta do projeto, execute:

```bash
python -m http.server 8000
```

Acesse http://localhost:8000 para a memória ou http://localhost:8000/corrida.html para a corrida.

## Arquivos

- `index.html`, `style.css`, `script.js`: jogo da memória.
- `corrida.html`, `corrida.css`, `corrida.js`: jogo de corrida.
